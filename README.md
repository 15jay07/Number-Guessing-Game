# Number-Guessing-Game
A small program asks the user to guess a secret number. The player has a limited number of attempts to guess correctly
 Python Number Guessing Game

 # Concepts Used

- Variables
- `if / else` statements
- `while` loops
- User input
- Boolean values
- Comparison operators
- Logical operators


 # What I Learned
This project helped me understand how loops and conditional statements can work together to control the flow of a program.

It was a small project, but it was useful practice for building logic from scratch.
